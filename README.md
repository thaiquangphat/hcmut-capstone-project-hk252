# CAPSTONE PROJECT REPORT

## Title

**Reinforcement Learning-Based Symbolic Reasoning For Complex And Logical Question Answering On Hybrid Knowledge**

## Abstract

This thesis investigates reinforcement learning-based symbolic reasoning methods for multi-hop question answering on hybrid knowledge sources. To address the limitations of large language models, such as hallucination, limited interpretability, and high computational cost, two approaches are proposed: a Neural Policy model (**NeuroPath**) and a Symbolic Hierarchical Reinforcement Learning framework (**SymR**). Experimental results on benchmark datasets demonstrate improvements in reasoning accuracy, coherence, and interpretability, highlighting the effectiveness of combining neural learning with structured symbolic decision-making.
